# 2026-08-11

## 抓娃娃模拟器 (index.html)
- Built a single-file Three.js claw machine game (CDN: unpkg three@0.160.0). Served via `python -m http.server 8137`.
- Controls: C = insert coin, WASD = move claw, Space = drop. 20s per play.
- Key mechanics: spring-damper cable sway (x/z), motor constant-speed cable (down 1.05 u/s, up 1.9 u/s), grip quality = centering / doll weight, slip over time, prize chute hole.
- User feedback round 1: dolls could never be grabbed because the descending claw pushed them away with an oversized radial force — fixed to contact-only collision (contactR = 0.3 + d.r, gentle impulse). Descent was too fast — switched from spring to constant motor speed. Grab radius widened to 0.65, success prob raised to 0.45 + q*0.55.
- User said frontend frameworks are allowed (permission, not requirement); kept single-file for zero-build simplicity.
- Round 2: added pointer-drag horizontal camera orbit (clamped ±0.6 rad, eased) + kept slight hover parallax. Rebuilt claw prongs as two-joint fingers (shoulder + elbow + cone tip, joint spheres); open/close drives both joints: shoulder 0.95→0.15 rad, elbow -0.5→-1.25 rad (curls inward).
- Round 3: split single HTML into index.html / style.css / game.js (ES module, importmap in HTML). Verified all served 200 on :8137.
- Round 4: added 3 difficulty modes (简单/普通/困难) as MODES config in game.js (grabR, baseP, pScale, slip fn). Easy: grabR 0.8, ~90%+ grab, slipAt=Infinity (never drops). Hard: narrow radius, weak grip. Mode persisted in localStorage 'claw-mode'. UI buttons in #modes below top HUD.
- Round 5: DOWN_SPEED 1.05→1.55. Added front control deck (tilted panel outside glass): 3D joystick (stick tilts with claw velocity, rotation.x=+vz*k, rotation.z=-vx*k) and coin slot (clickable via raycast on pointerup if moved <6px; lamp flashes on insert via slotFlash).
- Round 6: static assets moved to assets/ — assets/lib/three.module.js + RoomEnvironment.js (game now fully offline, importmap points local), assets/marquee.svg (neon sign texture), assets/mat.svg (floor mat texture). Glass realism: scene.environment via PMREM RoomEnvironment, glassMat clearcoat + envMapIntensity 1.8 + opacity 0.22, aluminum frame bars.
- GOTCHA: Windows python http.server zombies hold the port (double-bind allowed); symptom = curl 000 empty reply. Fix: netstat -ano | grep <port>, kill ALL stale PIDs via PowerShell Stop-Process, keep one server.
